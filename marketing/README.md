# 🚀 AutoHeal-CI Commercial Marketing Landing Page

This directory contains the standalone, high-converting product landing page for **AutoHeal-CI**.

## 🌟 Features Included
- **Tailwind CSS Dark-Mode Architecture**: Modern developer aesthetics (`bg-slate-950`, emerald glow, JetBrains Mono font).
- **Interactive ROI Calculator**: Real-time slider calculation computing monthly dev hours saved, annual payroll savings, and net ROI multiplier against the \$39/mo subscription.
- **Live Terminal Emulation**: Showcases AST slicing, Red-Team deliberation, and Sandbox verification.
- **3-Tier Good-Better-Best Pricing Matrix**: Community (Free), Pro (\$39/mo with "Most Popular" badge), Enterprise (\$499/mo).
- **Objection-Busting FAQ**: Directly addresses IP security, zero code leakage, and regression protection.

## ⚡ 1-Click Deployment Options

### Option 1: GitHub Pages (Free)
1. Go to your repo on GitHub: `Settings` -> `Pages`.
2. Under **Build and deployment** -> **Source**, select `Deploy from a branch`.
3. Choose branch `main` and folder `/marketing` (or configure via GitHub Actions).

### Option 2: Vercel (Free)
1. Import repository on [Vercel](https://vercel.com).
2. Set Root Directory to `marketing`.
3. Click **Deploy**. Your custom domain is live in 30 seconds!
