Got Questions?

Frequently Asked Questions

Does our proprietary code leak to external servers?

No. AutoHeal-CI runs completely inside your own GitHub Actions Runner. We slice only the exact AST tokens of the failing function via Tree-sitter (averaging under 2,000 tokens), rather than sending entire files. For Enterprise customers, we support 100% on-premises self-hosted LLMs (Ollama, vLLM) so zero bytes ever leave your firewall.

How do you prevent the AI from generating regressions or bad patches?

AutoHeal-CI uses an Adversarial Red-Team Critic loop and an isolated git worktree sandbox. The fix is only delivered if: (1) the original failing test passes, (2) the Red-Team Critic's adversarial edge-case test passes, and (3) 100% of the repository's existing test suite passes with zero regressions.

How long does it take to integrate?

Under 2 minutes. You simply add 8 lines of YAML to your .github/workflows/ci.yml file under if: failure(). AutoHeal-CI sits idle with zero CPU overhead until a test actually fails.
